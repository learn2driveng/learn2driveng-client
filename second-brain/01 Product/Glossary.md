# Glossary

| Term               | Project meaning                                                        |
| ------------------ | ---------------------------------------------------------------------- |
| FRSC               | Federal Road Safety Corps; verification is a core trust signal         |
| Package definition | A school-created training product offered for sale                     |
| Package purchase   | A learner-owned instance of a package after payment                    |
| Session credit     | One bookable lesson remaining within a package purchase                |
| Booking            | A learner's reservation for a future lesson                            |
| Session            | The actual lesson conducted from a confirmed booking                   |
| Total balance      | Sum of remaining credits across active package purchases               |
| Public marketplace | School and package discovery available without login                   |
| Protected action   | Payment, booking, saving, or viewing personal data                     |
| Return-to          | Internal route preserved across login so an intended action can resume |
| Presentation data  | Typed local mock data used before API integration                      |
