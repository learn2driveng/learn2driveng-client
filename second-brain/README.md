# Learn2Drive Second Brain

This folder is an Obsidian-ready knowledge vault for the Learn2Drive mobile
project. It records both product intent and the reality of the current codebase.

## Open the vault

1. Open Obsidian.
2. Choose **Open folder as vault**.
3. Select this `second-brain` folder.
4. Start at [[00 - Home]] or open [[Learn2Drive Map.canvas]].

No community plugins are required. Notes use standard Markdown, properties,
WikiLinks, and an Obsidian Canvas.

## Working convention

- Capture rough thoughts in [[Inbox]].
- Update [[04 Delivery/Current State]] after meaningful implementation work.
- Record architectural changes using [[06 Templates/ADR Template]].
- Create feature notes from [[06 Templates/Feature Note Template]].
- Link claims to code or source documents whenever possible.
- Mark planned work as planned; never describe it as implemented.

## Source of truth

The source code is authoritative for current implementation. Existing documents
under `../docs/` describe intent and previous decisions, but some planned
architecture is not implemented yet.
